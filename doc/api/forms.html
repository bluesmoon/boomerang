The Forms Plugin

The forms Plugin tracks all form submissions on a page and beacons them to a dedicated endpoint on your beacon-server.

The forms API is encapsulated in the BOOMR.plugins.forms namespace

WARNING: Be aware that this plugin uses the HTTP POST-Method to send data to the beacon-server as it can not anticipate the size of the to be sent data entirely

Configuration

The forms plugin configuration is contained in the forms namespace in the initial Boomerang configuration Object.

See "Howto #6 — Configuring boomerang" for more information on how to configure Boomerang

forms_url
[required] The Url the form submission events are supposed to be sent to. You need to specify this.

Methods

init(oConfig)

Called by the BOOMR.init() method to configure the forms plugin. 

      BOOMR.init({
        forms: {
          forms_url: "http://<your beacon server>/forms"
        }
      });

Parameters

oConfig
The configuration object passed in via BOOMR.init(). See the Configuration section for details.

Returns

a reference to the BOOMR.plugins.forms object, so you can chain methods.

Beacon Parameters

The following parameters are sent when a forms event is triggered.

form_data
An array of JSON.stringified values from the submitted form

The following parameters are contained in the Object which is part of the submitted form_data Array

name
The name attribute of the submitted input form element
value
The value of the submitted input form element
type
The type of element to be submit
id
The id of the element

For a simple input form the returned values may look like this:

    "form_data": [
        {
            "name": "name",
            "value": "Andreas Marschke",
            "type": "text",
            "id": "text"
        },
        {
            "name": "email",
            "value": "andreas.marschke@gmail.com",
            "type": "email",
            "id": "email"
        },
        {
            "name": "comment",
            "value": "Thank you for this dishwashing ninja!",
            "type": "textarea",
            "id": "textarea"
        }
    ]
